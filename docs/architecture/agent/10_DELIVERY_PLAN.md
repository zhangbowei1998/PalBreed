# 10. 交付与里程碑

## 1. 里程碑拆分

### M1: 核心链路可用

- app/graph/state/clients 最小可运行
- 首问 -> Top-3 -> 确认 -> 一层展开
- 基础单元测试

### M2: 交互增强

- 多轮展开与循环保护
- interaction 文案与动作协议稳定
- 生成路线（explored_only）

### M3: 质量与运维

- 完整集成/冒烟测试
- 可观测性指标上线
- 性能优化与配置调优

## 2. 开发分工建议

- A 组：graph + state
- B 组：clients + interaction
- C 组：summarizer + 测试平台

## 3. AI 接手执行清单

1. 先读 README 与 01/02 文档，理解边界。
2. 按包文档逐个实现，不跨包越权。
3. 每完成一个包先补单测再联调。
4. 联调失败优先检查契约文档，不直接改对方包内部。

## 4. 完成定义（DoD）

- 所有包具备职责内实现与测试。
- 三层测试全部通过。
- 输出契约满足前端联调。
- 文档与实现一致。
