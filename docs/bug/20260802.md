## 调查结论（2026-08-02，最终版）

> 之前初版曾误判「系统数据正确、用户看错」。经用户提供权威数据源后查明：**系统配种规则确实有误**，用户实测正确。根因与修复如下。

### ✅ 根因（Palworld 真实配种规则）
Palworld 配种规则比「rank 平均」更复杂：
1. **`breedChild`**：部分帕鲁（116 只稀有/变种/传说，如梆梆鲶、空涡龙、腾炎龙）**不能作为普通配种结果产出**。avg=1620 落在梆梆鲶，但梆梆鲶不可配种 → 取最近的可配种帕鲁 = 烽歌龙(1650)。
2. **独特组合**：`breedChild=False` 的帕鲁只能通过独特组合获得（同种配对 same_species / 固定配方 fixed_pair）。

系统此前**缺 `breed_child` 字段 + `breeding_rule` 表为空**，只按 `round((A+B)/2)` 精确匹配 → 「壶小象+腾炎龙」被错误算成梆梆鲶。

### ✅ 修复（数据源切换为 tc-imba）
- 数据源改用 **palworld.tc-imba.com**（玩家自建、从游戏文件提取）：`pals.json`（属性）+ `breeding.json`（rank/breedChild/独特组合）+ locales（中英文名）。
- 新增 `breed_child` 字段：`Pal` schema、`pal` 表、ORM 模型、seed 流程全链路。
- 导入 250 条独特组合到 `breeding_rule`（114 same_species + 136 fixed_pair）。
- 配种查询改造：
  - `query_parent_pairs_by_rank` 改为「独占区间」反向查询（只考虑 `breed_child=True` 帕鲁）
  - `_breeding_query` 合并独特组合 + rank 公式（不互斥）
  - `DataLoader.find_nearest_rank` 过滤不可配种帕鲁
- 新增 `scripts/convert_tcimba.py`（tc-imba → pal_data.json）、`scripts/seed_breeding_rules.py`（独特组合入库）；api 容器启动时自动灌入。

### ✅ 验证
- 「壶小象 + 腾炎龙」：tc-imba 配种计算器 = **烽歌龙**（与用户实测、paldb.cc 一致）
- 端到端 API：
  - 梆梆鲶 父母 = 2 种独特组合（趴趴鲶+祇岳鹿、同种），**不再含腾炎龙** ✅

  - 空涡龙 = 同种独特组合 ✅；阿努比斯 = 231 对 rank 公式 ✅
- 全量测试 113 passed；api 容器重建后 seed 299 pal + 250 rules 正常。
